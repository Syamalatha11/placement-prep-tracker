# Placement Prep Tracker

A single-page placement preparation tracker designed for campus placement prep. It helps you:

- plan daily tasks across Aptitude, Coding, English, and Development
- track progress and completion percentage
- manage a study schedule with a built-in Pomodoro timer
- log mock test scores and revision notes
- review topics to cover and keep progress organized
- use a built-in mentorship chat prompt flow for study guidance

## Files

- `index.html` — main app

## How to use

1. Open `index.html` in a browser.
2. Fill in your name, target type, start date, and preparation duration.
3. Use the dashboard to track tasks, mock tests, notes, and progress.
4. Use the floating mentor button to get quick study guidance.

## Deployment

This project is compatible with GitHub Pages. To publish it:

1. Go to the repository settings.
2. Open **Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select **main** and **/ (root)**.
5. Save.

## Notes

- The app stores data in `localStorage`, so progress stays saved in the browser.
- The file is designed as a lightweight single-page app and does not require a build step.
